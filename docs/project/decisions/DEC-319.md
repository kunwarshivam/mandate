# DEC-319: DEC-290 item 6's re-run is not a kill switch

|---|---|

## Decision

1. DEC-290 item 6's sentence "The report after the last names the event id, which a re-run finds if
   nothing else has been committed since" reads as "… which a re-run (not a kill switch, item 5)
   finds …". The kill switch is DEC-290 item 5's own path and is never found by a re-run.
2. DEC-290's row is not edited. DEC-344 item 3 lets a PR edit only its own decision files, so the
   clarification is recorded here.

## Rationale

The coordinator's carry-over from #418 asked for this wording. [DEC-344](DEC-344.md) landed before
it reached a PR, so it is recorded as its own decision rather than as an edit to DEC-290's text.

## Alternatives considered

- **Editing DEC-290's row in place.** Rejected: DEC-344 forbids it.

# DEC-904: The signed-out pages can wear a classic Mac desktop as well as Windows 98, chosen with the other computer's icon on the desktop; Windows stays the default until the Mac is finished

| | |
|---|---|
| **Status** | Accepted |
| **Date** | 2026-10-10 (UTC) |
| **Decided by** | The founder, who asked to "redesign from windows to Mac", with "a switch that changes the style to MacOs design", keeping the pixel art, and to make the Mac the default "once it is complete"; then for the switch to be "an icon on desktop" that does not "mention what it does", with nothing written at the bottom, and for the Mac to be "more obviously mac"; the agent chose the details under DEC-79, since none touches money, legal text or a safety rule |
| **Story or claim** | Landing page (DEC-212, DEC-218, DEC-467, DEC-903) |

## Decision

1. **Two desktops, one page.** The landing page and the sign-in pages wear either Windows 98 or
   the Mac's System 7 (`src/lib/desktop-style.ts`). The choice is kept in the `owlhead-desktop`
   cookie for a year; the server reads it in `app/(site)/layout.tsx` and draws the chosen desktop,
   so nothing swaps after the page paints. A missing or unknown value draws Windows.
2. **The switch is the other computer.** Among the desktop icons sits the other desktop's
   computer, named for the computer alone: a compact Mac, "Mac", on Windows, and a PC, "PC", on the
   Mac (`MAC` and `PC` in `pixel-icons.tsx`). Choosing it swaps the desktop. Nothing on screen says
   what it does; its accessible description does, for assistive technology. It is in the Start menu
   and the owl's menu too, since the icons are out of the tab order. The windows, their places and
   what is open stay as they were.
3. **The Mac is System 7 in one bit, over the same markup.** The frame carries `data-os`, and the
   letter's Mac rules (`letter.module.css`) turn grey to white (`--muted` becomes the card), bevels
   into one-pixel ink boxes, windows and menus white with a hard two-pixel ink shadow, buttons round
   and bold, the default one ringed as the Mac ringed it, and scroll bars into a grey track ruled off
   in ink with a white thumb. The title bar (`title-bar.tsx`) is pinstriped with a bold title, the
   close box at the left and zoom and collapse at the right, all hidden while the window is behind.
   The same three controls keep the same names in both styles.
4. **The Mac desktop's furniture.** The desktop is the 50% grey pattern a one-bit Mac drew, until a
   painting is picked (`wallpaper.tsx`; Display Properties lists it as "Desktop pattern"). A menu bar
   along the top, in bold, replaces the taskbar: the owl's menu in the Apple menu's place (About
   Owlhead and every app), File (open the home page, close the window in front, sign in; Print greyed
   out), Edit (all greyed out, since nothing on the desktop can be edited), Special (wallpaper, dark
   mode as a checked item, the owl, Empty Trash, Shut down), the clock, and at the far right the
   windows menu, its title the front window's icon, which checks the window in front, hides it and
   brings back any open one; a window collapses into it. A browser on a Mac kept its menus in the
   menu bar, so the home page's window draws none. The icons sit down the right edge under the hard
   disk, "Owlhead HD", which opens the home page; the Recycle Bin is the Trash, at the bottom right.
   The pixel art, the faces, the wordmark and the motion of DEC-903 are the same in both.
5. **Windows stays the default** until the founder calls the Mac finished; then `DEFAULT_DESKTOP`
   changes and this decision's item 1 is amended.

## Rationale

The founder wants the desktop to become a Mac but asked to see it beside the current one first, so
a switch lets both be judged on the real page, and keeping Windows the default means nothing
changes for a visitor until the Mac is done. Overriding the shared style constants by one
attribute, rather than forking each component, keeps one set of windows, apps and tests; the
components whose shape differs (the title bar, the taskbar against the menu bar, the dark mode
toggle) read the style from context.

## Alternatives considered

- **Only a Mac.** The founder asked for a switch first and the Mac as default once complete.
- **Mac OS 8's Platinum, or Aqua.** Platinum is grey and bevelled like Windows, so the two would
  barely differ; Aqua leans on gradients and glows, which `web/DESIGN.md` forbids. System 7's one
  bit sits on the same pixel grid as the owls.
- **Chicago for the chrome.** It would be a new font to license and host; Pixelify Sans stays.
- **The choice in local storage.** The server could not draw it, so the Windows desktop would flash
  before the Mac replaced it.

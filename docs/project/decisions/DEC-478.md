## Decision

This amends DEC-200's icon choice (Phosphor) for the app's own code.

1. **Pixelarticons is the icon set** (`pixelarticons`, MIT, pinned `2.4.1`): hand-drawn pixel
   glyphs that belong with the pixel owls. Phosphor stays installed only because Kumo, pinned,
   imports it inside its own components; app code may not import Phosphor or Lucide.
2. **One file per icon.** `import { Home } from "pixelarticons/react/Home.js"`. ESLint bans
   `@phosphor-icons/*`, `lucide-react` and the Pixelarticons barrels in `src/`, so the rule is
   checked, not guided.
3. **24px or 48px, never in between.** Each glyph is drawn on a 24px grid without anti-aliasing, so
   it renders at 24px (`size-6`) or 48px (`size-12`). A glyph sits inside its square with room
   around it, so a 24px pixel icon reads at the size a 16px outline icon did. Beside small type it
   takes a negative margin so the line keeps its height. Kumo menus draw an icon component at 16px,
   so menus get the icon as an element at 24px (`menuIcon`). The dock's icons go from 20px to 24px,
   the tab bar's from 22px to 24px, and the performance disclosure's glyph from 16px to 24px, the
   size of its target (DEC-210's target is unchanged).
4. **No filled current state.** The set has a solid variant for a handful of glyphs only, so a
   current dock item, tab or More row is marked by its pill, its semibold label and
   `aria-current`, not by a filled icon, and the mode pill by its fill alone.
5. **Stop keeps its octagon** (DEC-206). The set has none, so `StopOctagon`
   (`web/src/components/icon.ts`) draws a solid stepped octagon on the same grid.

The 8px "Mini" set, the only one crisp at 16px, is paid, and buying it is the founder's call
(DEC-79); nothing here needs it.

## Rationale

The founder judged Phosphor, and then Lucide, generic: the outline sets every generated interface
uses. Pixelarticons is distinctive, free, has no runtime dependency, and matches the pixel owls
that already carry the brand. Rendering it off its grid blurs it, so the size rule is part of the
choice, not polish.

## Alternatives considered

- **Keep Phosphor** (DEC-200): rejected by the founder.
- **Lucide, Tabler, Remix, Heroicons:** the same outline look the founder called slop.
- **Pixelarticons at 16px:** each pixel would be two-thirds of a CSS pixel and blur.
- **Remove Phosphor entirely:** Kumo's menus, dialogs and fields import it, so it cannot go while
  Kumo is pinned.

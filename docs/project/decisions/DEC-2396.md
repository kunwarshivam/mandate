## Context

DEC-997 chose OpenRouter, routing locked to one upstream with zero data retention, and $50 a month
per workspace. Three things a live call needs are still unnamed, and each is the founder's:

1. **The model**: the registry entry the service serves live, meaning its OpenRouter slug, its one
   upstream, the dated snapshot it serves, and its prices (DEC-2257 item 7, DEC-2265 item 10).
2. **The deployment's monthly cap**: `MANDATE_GATEWAY_DEPLOYMENT_MONTHLY_USD`, which DEC-2326
   item 2 leaves unset.
3. **The workspace cap's value in the chart**: `MANDATE_GATEWAY_WORKSPACE_MONTHLY_USD`. DEC-997
   names $50, and DEC-2203 item 9 says "$50 is my demo cap and not customer".

**Finding that shapes every option.** OpenRouter's zero-data-retention endpoint list
(`/api/v1/endpoints/zdr`, read 2026-10-26) holds no first-party endpoint for Anthropic, OpenAI or
Google AI Studio. Its ZDR guide says the Anthropic scope "removes first-party Anthropic endpoints
(Bedrock and Vertex remain available)", and the OpenAI scope does the same, with Azure remaining.
So DEC-997 item 2's lock to one upstream with `provider.zdr: true` can only be met through a cloud
reseller: Google Vertex for Claude or Gemini, and Azure for OpenAI. A lock to `anthropic` would
pass no call, which is the safe outcome, but it would also never run.

## Options

Prices are OpenRouter's public list, in USD per million tokens (input / output / cached input),
read 2026-10-26 from `openrouter.ai/api/v1/models/{slug}/endpoints`. A run here is 8 turns of 20k
tokens in and 2k out, with no cache hits.

| | A. Claude Sonnet 5.5 (recommended) | B. Claude Haiku 5.5 | C. GPT-5.6 Terra |
|---|---|---|---|
| OpenRouter slug | `anthropic/claude-sonnet-5.5` | `anthropic/claude-haiku-5.5` | `openai/gpt-5.6-terra` |
| One upstream (`provider.only`) | `google-vertex/global` | `google-vertex/global` | `azure` |
| ZDR on that upstream | yes | yes | yes |
| Snapshot the entry pins | `claude-sonnet-5-5`. Anthropic states that every model id, including the dateless ones, is a pinned snapshot | `claude-haiku-5-5`, the same | `gpt-5.6-terra`, OpenAI's "default snapshot", undated |
| Price | 2 / 10 / 0.10 | 0.10 / 0.50 / 0.01 (Anthropic shows "from", so it may be tiered) | 2 / 12 / 0.20 |
| Tool calling and `structured_outputs` | yes | yes | yes |
| Cost of one run | about $0.48 | about $0.024 | about $0.51 |
| Runs in $50 a month | about 104, or 3 a day | about 2,080, or 69 a day | about 97 |

**Recommendation: A**, Claude Sonnet 5.5 through `google-vertex/global` alone. It writes the
theses the platform asks the owner to rely on, and the platform's agent harness and recorded
bundles were written against Claude's tool-calling form. At three runs a day it fits a paper
demo's cadence: one discovery run before the open and a few re-checks. If the founder wants a
higher cadence inside the same $50, B is the same family, served by the same single upstream, at a
twentieth of the cost. C needs a second vendor relationship (Azure) for no gain here.

**Deployment cap: equal to the workspace cap, $50 a month.** Today a deployment holds one
workspace (DEC-2207), so any lower figure would bind before the workspace cap does, and any higher
one would be inert. When a deployment serves several workspaces, this becomes a new decision.

## Decision (as proposed)

1. **The live entry** is option A: slug `anthropic/claude-sonnet-5.5`, routed `provider.only`
   and `provider.order` to `google-vertex/global` with `allow_fallbacks: false`,
   `require_parameters: true`, `zdr: true` and `data_collection: deny` (DEC-997 item 2). The
   snapshot is `claude-sonnet-5-5`. The price table is 2 / 10 / 0.10 per million, and the reported
   model and provider are fixed by the inference spec §4.3 identity probe before the endpoint is
   added.
2. **The budgets the chart renders for the founder's own workspace**:
   `MANDATE_GATEWAY_WORKSPACE_MONTHLY_USD=50` and `MANDATE_GATEWAY_DEPLOYMENT_MONTHLY_USD=50`.
   Customer budgets remain configuration and a later decision (DEC-2203 item 9).
3. **The prices are re-read before the entry is mounted.** OpenRouter's list and its ZDR endpoints
   can change. The agent that writes the registry file re-reads both on the day, and a change in
   either goes back to the founder before anything is mounted.
4. **Nothing spends until the key is in the vault.** The founder writes the OpenRouter key into the
   cell's vault (the runbook step under E21-62). No agent asks for, reads or handles it
   (`AGENTS.md` rules 7 and 8).

## What the founder is asked

- Accept A, or choose B or C?
- The deployment cap at $50 a month, equal to the workspace cap?

## Consequences

- On acceptance, a later change supersedes DEC-2326 items 1 to 3 for this entry. That change
  mounts the registry file, sets the two variables, and builds the live start.
- Until then, the binary serves the recorded bundle only, and every live start is refused.

## Decision

1. **When.** An order whose answer was lost is `Unknown` (§5.7). Where the profile can query by
   client order id, nothing changes: `GetOrderByClientId`. Where it cannot, the executor sends
   `BrokerRequest::ListOrders` in its place, and never `GetOrderByClientId`, a resubmission or a
   lookup on the absence timer. On such a profile `Unknown → Intent` never fires (§5.7).
2. **The listing.** It names the order it is for, the order's instrument, the origin `agentic`, and
   `created_since`, the order's `OrderSubmitted` risk clock less a fixed margin of **300 s**. The
   risk clock is the scheduler's and the broker stamps its own time; a wider window only adds
   candidates, and more candidates can only leave the order `Unknown`.
3. **Dedicated to one agent.** The executor reads DEC-529 item 4's "the account ledger shows the
   account dedicated to one agent" from its own account stream: every intent and every order it
   has folded names the `Unknown` order's agent. Otherwise it sends no listing, the order stays
   `Unknown`, and a listing answer it did not ask for adopts nothing.
4. **A match.** A listed record matches only if its instrument, side, quantity, limit price,
   order type and time in force equal the order's as journaled, and its client order id is
   absent or ours. A record naming another client order id is another order. Records are counted
   as listed, so a record listed twice is two matches.
5. **Adoption.** Exactly one match is folded as the broker's description of our order, through
   §5.7's status table, so the order leaves `Unknown` by a journaled `OrderStateChanged`. It
   invents no fill and cancels nothing. Zero or several matches leave it `Unknown`, its instrument
   blocked (§5.3 rule 9), until the owner reconciles it; nothing is re-listed on its own.

## Rationale

Every item narrows what is adopted or sent: a wrong `Unknown` blocks an instrument until the
founder looks; a wrong adoption could free it for a second order (rules 3 and 13, LT-6).

## Alternatives considered

A margin in `ExecutorConfig` (it changes every configuration reader for a value nothing tunes
yet); re-listing on the absence timer (DEC-529 item 4 leaves zero matches to the owner).

# DEC-2521: The respond route refuses a grant whose request and decision disagree on deferred checks

| | |
|---|---|
| **Status** | Reserved |
| **Date** | 2026-10-26 (UTC) |
| **Decided by** | `claude-code` (lane GL) |
| **Story or claim** | DEC-2519's alternatives (the respond-route follow-up); [workspace API spec](../../specs/workspace-api.md) §5.2 |

Reserved by lane GL. `POST /approvals/{id}/responses` refuses a grant, `409` `deferral_mismatch`, when the request's
deferred checks are not exactly its decision's, or its decision cannot be found. A Skip is never refused for it.

## Context

The founder's direction of 2026-10-17: the product is an agent harness for trading, agentic where it
thinks and deterministic where it touches money. DEC-192 already decided that "why did it do that?"
is answered from the journal, that a model may phrase the answer but adds no fact, and that a
missing fact reads "not recorded"; no spec said how. Lane AH (E19-13) is building the bounded tool
loop for research; this decision places a second caller of that loop, owner-facing and read-only.

## Decision

1. **Where it runs.** In the workspace services, beside the compiler, never in the agent process.
   Its records are on the workspace's control stream, which the services own (journal spec §2). The
   agent process, its tick, its research worker, and its budgets do not change (spec §15.1).
2. **What it may read.** Only the session's workspace and the one agent the request names: that
   agent's stream; the account-stream records naming its intents or its id; the control-stream
   records naming it; the mandate documents its versions name. The scope `(workspace, agent,
   principal)` is fixed from the authenticated request before the first turn; no tool argument can
   name a workspace, stream, role, or principal; a foreign id and an absent one return the same
   `not_found` (EX-2, EX-3, API-9). Who may ask: the *Chat thread with the agent* row (operator); a
   client cannot. The approval draft is read with the approval (*View agents, positions,
   decisions*). No permission-matrix row is added or widened.
3. **Read only, rung 1.** Thirteen read tools (spec §15.4). The explainer's crate depends on no
   runtime, executor, connector, approval-writer, or vault crate, so it cannot name an order,
   approval, command, or credential path (EX-1).
4. **Least context: the redacted projection.** Tool results carry identifiers, times, symbols,
   sides, reason codes, rule and limit names, states, and the agent's own model text. They never
   carry a quantity, price, limit value, dollar figure, P&L, account reference, or broker number.
   The web app renders the cited records, with their figures, from the journal (EX-6). This keeps
   `AGENTS.md`'s "Do not" (no order details or positions in anything that leaves the workspace
   deployment) on a path whose prompts go to a hosted provider. It tightens; the founder may later
   decide to send figures.
5. **Grounding checks, deterministic, in order:** `uncited_segment`, `unknown_citation`,
   `advice_language`, `too_long`. Any failure shows no model text and falls back to the
   deterministic records the tools returned. No re-sampling (DEC-432 item 3's reasoning: sampling
   until something passes selects outputs).
6. **Not advice.** The template describes and never advises; the check refuses recommendations,
   imperatives to approve or skip, price targets, and profit claims (DEC-126); the approval draft
   never says how to answer. The disclaimer is a named placeholder (DEC-2241).
7. **Records** (journal spec v0.48 §9.22): `ExplanationRequested` (its event id is the
   explanation's id; a guard-refused question is never stored), one `ModelInvocationRecorded`
   version 2 per turn on the control stream (purposes `compiler` and `explain`, with §9.19's
   nullable `prompt_ref`, which also unblocks DEC-998 item 2 for the compiler), and
   `ExplanationRecorded` (outcome, turns, tool-call ledger, answer artifact, citations, disclaimer
   key), committed before any answer is returned. `MeterReserved` version 2 adds the purpose
   `explain` with no agent. Rules 180 to 189. Version 1 of both records stays registered. Rule
   numbers 165 to 179 and §9.21 are left for lane AH's E19-13 records so the two lanes never collide.
8. **Bounds** (spec §15.7): a 1,000-character question; 6 turns; 4 tool calls a turn and 16 an
   explanation; §15.4's row caps and 16 KiB a result; 60 s wall time; 1 explanation in flight per
   member and 4 per workspace; 30 questions per member per risk day.
9. **Spend.** The explainer's own caps, $1.00 per workspace per risk day and $10.00 per workspace
   per month, folded over the meter stream's `explain` reservations, inside DEC-997's $50.00 a month
   per workspace, which every explain call also counts against. These only refuse calls and spend
   less than the founder's cap allows, so they are an agent's tightening; raising the workspace cap
   stays the founder's. No agent's research cap is spent by its owner's questions (rule 189).
10. **The approval draft.** At most one per approval, started by the first read of a pending
    approval by a principal who may view it, outside `content` and `content_hash` (API-12). The read
    never waits for it; a missing or late draft only leaves the card without one (EX-9, rule 3).
11. **Precondition.** No explanation call is made until the inference spec admits a tool-calling
    entry under E19-13's change to INF-5 and `mandate-journal` registers §9.22's records; until then
    the route serves the deterministic fallback (spec §15.1).
12. **Fixtures.** CI and the demo use recorded-fake gateway responses only, with no network (rule 8,
    DEC-997 item 4).
13. **Number ranges.** This lane takes DEC-2240 to DEC-2249 so that it never races lane AH and lane
    I1 for the next number in the DEC-2200 range.

## Rationale

The journal already holds the real reasons (rule 5), so the honest explanation is one assembled
from it; a model only phrases it. A loop over tools, rather than one call with a fixed retrieval,
lets the explainer answer open questions without loading the whole journal into a prompt, and the
tool boundary is where tenant isolation and redaction are enforced in code. Keeping it in the
workspace services and off every risk path means no question, outage, or cost cap can change what an
agent does.

## Alternatives considered

- **Run the explainer inside the agent process.** Rejected: it would put a member-driven,
  interactive model loop beside the trading tick (HI-7, HI-21) and spend the agent's research cap.
- **Send figures to the model.** Rejected for now: the "Do not" rule and INF-8's spirit; the
  deterministic citation cards show the figures anyway.
- **Let the model answer freely, or show the raw trace only.** DEC-192 rejected both.
- **Re-sample until an answer passes the checks.** Rejected: it selects outputs and multiplies cost.
- **One combined record per explanation, no per-turn record.** Rejected: INF-10 and INF-6 need each
  call's record before its output is used and metered.

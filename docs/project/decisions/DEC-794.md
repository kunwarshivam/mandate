# DEC-794: CodeQL ignores only the web push crate's published RFC test vectors

| | |
|---|---|
| **Status** | Accepted |
| **Date** | 2026-10-08 (UTC) |
| **Decided by** | The L3 builder agent at the L3 lane lead's direction, under DEC-79 (a reversible engineering reading) and on DEC-500's paved path; it disables no query |
| **Story or claim** | E8-14, slice S8a, claim [#753](https://github.com/kunwarshivam/mandate/issues/753); CodeQL's two "Hard-coded cryptographic value" alerts on [#800](https://github.com/kunwarshivam/mandate/pull/800); precedent [DEC-500](DEC-500.md) |

## Decision

1. **The vectors live in one test-only directory**, `crates/mandate-webpush/tests/vectors/`. It
   holds RFC 8291 §5 and Appendix A's keys, salt and message, RFC 8188 §3.1's input keying material
   and message, and the fixtures that carry them (the scripted random source, the test signer, the
   receiver-side decrypt). They are published test vectors, never used outside tests.
2. **CodeQL skips exactly that directory** (`paths-ignore` in `.github/codeql/codeql-config.yml`).
   Every query, the hard-coded cryptographic value query included, still runs on every other path,
   the crate's `src/` and the rest of its tests included. No alert is dismissed.
3. **No product path may read them.** Only `src/tests.rs`, compiled under `#[cfg(test)]`, includes
   the directory. Its live test `no_product_code_reaches_the_rfc_vectors` fails if `src/lib.rs` or
   `src/payload.rs` names it, or if the tests module stops being test-only. Cargo builds no target
   from a subdirectory of `tests/`.

## Rationale

A byte-exact RFC vector test needs the RFC's fixed keys and salt in the source. The query is right
that a fixed key in product code is a defect, so it keeps running everywhere a product key could
appear, and the one place it is told to skip is pinned by a test to stay out of the product.

## Alternatives considered

- **Dismissing the alerts.** Rejected: a dismissal is invisible in the code and does not stop the
  next copy of the pattern.
- **Excluding the query.** Rejected: DEC-500 item 2 excludes a query only on its own evidence, and
  this one is correct about product code.
- **Generating the keys at test time.** Rejected: the RFC vectors are only reproducible with the
  RFC's own keys.

# DEC-762: Trace bounds: 16 hops, 256 events, each event once, and statuses for every hop

| | |
|---|---|
| **Status** | Accepted |
| **Date** | 2026-10-08 (UTC) |
| **Decided by** | The agent in lane L5, under DEC-79 and DEC-176: closes an unclosed contract by the reading that adds no risk (DEC-176 item 2) |
| **Story or claim** | E12-6 ([#756](https://github.com/kunwarshivam/mandate/issues/756)); E12-1 (#745), E12-2 (#747), E12-3 (#748); workspace API spec §4.8.1 |

## Decision

1. Breadth first from the start event, in the link table's order and each list's order.
2. At most 16 hops deep, 256 events, and 1,024 recorded hops; a link a bound stops is
   `beyond_bound`, the response says `truncated: true`, and after 1,024 hops nothing more is
   recorded. All reads use one snapshot, and `as_of` is one watermark per stream read.
3. Each event is shown once; a link to a shown event is `already_shown` and is not followed, which
   ends cycles and self-links.
4. A target absent, malformed, in another workspace, or on a stream the row does not name is
   `not_recorded`, never an error, and foreign is indistinguishable from absent.
5. A target in the workspace of a type the row does not name is `unexpected_type` with the found
   type, shown and not followed.
6. Model-authored members are served only in each node's `quoted` list (API-18). Each item is
   `{path, quoted}`: `path` the JSON Pointer of the member in the event body, and `quoted` a
   `QuotedContent` of `schemas/workspace-api/common.schema.json` (DEC-740 item 8) exactly as that
   schema closes it (`author`, `text`, `model_id`, `model_version`, `produced_at`, `event_id`,
   `artifact`), since it has no member for the path. `author` is `owner_selected` only for a
   signal model the agent's confirmed mandate names, and `platform_authored` otherwise and when the
   trace cannot tell. An artifact member is named by `artifact` with `text` empty, never inlined;
   the model's content hash stays in the node's `body`.
7. Every node carries its `stream_id`, since a trace spans streams and `as_of` is per stream.

## Rationale

The longest recorded chain for an approved fill is 8 hops; 16 leaves room for copies without
letting a crafted graph hang a request. 256 events bounds the fan-out of `outputs_used` and
`evidence`. "Not recorded" is the backlog's wording for a missing fact (E12-5) and leaks nothing.

## Alternatives considered

- **Error on a cycle or a foreign link.** Rejected: an error distinguishes foreign from absent and
  hides the rest of a valid trace.
- **Unbounded walk.** Rejected: a denial of service on the audit path.

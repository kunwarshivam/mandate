## Context

On the rehearsal's clock (DEC-962) step 2l stopped at `the tracer stopped at Validate: a mandate
with no validation or policy violations`: V-001. The shell's run context
(`crates/mandate-shell/src/paper/context.rs`, `run_context`) handed the mandate validator
`connection_environment: Some(Paper)`, a constant from the paper adapter's first slice, so every
`live` mandate broke V-001 at the cycle's validation, although `version confirm` and `agent
deploy` had validated it against the recorded live connection. A probe build with only that
constant replaced showed two more constants of the same kind behind it, on the same path: the
cycle's admission refused every mandate that was not `paper` (`ShellError::NonPaperEnvironment`,
`the tracer runs only against the paper environment`), and every draft's envelope said the
constant `paper` (`envelope::ENVIRONMENT`), which a live workspace's streams, opened `live`
(DEC-952), would carry wrongly or refuse.

## Decision

1. **The run context names the chosen connection's environment.** `load_contexts` and
   `load_contexts_with_clock` take `connection: Environment`, the environment of the connection
   the run chose, and `run_context` hands V-001 `Some(connection)`. `mandate-paper`'s `run()`
   passes `connection.environment` of the live door's choice (`chosen`, the connection record
   DEC-924's admission passed on), never a constant. A paper connection validates exactly as
   before; a live mandate on a live connection passes V-001; and any mismatch between the
   mandate's environment and the connection's still fires V-001 (a property test over mandate
   and connection environment pairs pins it). The door's `connection` already refuses a record
   whose environment is not the mandate's (`connection_environment`), so V-001 is the second,
   independent check.
2. **The cycle admits a mandate only in the chosen connection's environment.** `Setup` carries
   `connection_environment`, set by `run()` (and by the own-fill booking) from the same
   connection. `admit` refuses `ShellError::EnvironmentMismatch` (`environment_mismatch`) when
   the admitted mandate's environment is not that one, before any stream exists. It replaces
   `NonPaperEnvironment`: on a paper connection a `live` or `backtest` mandate refuses exactly as
   before, under the new code; on a live connection a `paper` or `backtest` mandate refuses.
3. **Every draft says the chosen connection's environment.** `Envelope` carries `environment`,
   which every draft the shell composes takes from `Setup::connection_environment`
   (`journal_environment`); the constant `ENVIRONMENT` is gone. TI-7 (E7-7) is read as: every
   journaled draft carries the run's connection's environment, and item 2 ensures the admitted
   mandate's is the same. Every paper run still journals `paper` only; the paper scanner test
   is unchanged and a new one scans a live run for `live`.
4. **Places that name `paper` and stay.** `crates/mandate-shell/src/control.rs:372` (DEC-505
   item 3): the fold's value for a connection the control stream holds no record of. The only
   connection the door can choose for such a mandate is `paper_default`'s paper one, and a live
   mandate there is refused `Unrecorded` by the door and V-001 by the fold, so the constant is the
   chosen connection's environment by construction. The test doubles and fixtures that build
   paper runs stay paper. One more constant was found that is not an environment:
   `crates/mandate-shell/src/tracer.rs:779` opens a missing account stream with `broker`
   `alpaca`. A live run never reaches it (the connect check opens the live account stream
   first, observed at seq 1 of `acct:ws_r0:<ref>`), so it is recorded, not changed.
5. **Rehearsal result.** With these three changes the live run passes V-001 and the admission,
   and the shell journals the agent stream's `StreamOpened` as `live`. The rehearsal stops at two
   new blockers, recorded in the rehearsal record as R14 (2m and 2s: the runtime's fold refuses
   the account stream's `ConnectionChecked`) and R15 (2l on the Monday clock: the model's output
   from Friday's close is past the mandate's `max_output_age_s`, so the dry run decides nothing
   and prints nothing). Neither is fixed here (the brief: record and stop).

## Rationale

A constant cannot say which connection a run is on; the connection record the door chose can,
and DEC-924 made that choice the gate for a live run. Taking all three values from it keeps one
source for the run's environment and three independent refusals of a mismatch (the door's
record check, V-001, and the admission), where before there were three locks that refused every
live run whatever its connection.

## Alternatives considered

- **Take the environment from the mandate itself.** Rejected: V-001 would then compare the
  mandate with itself and could never fire.
- **Fix only the run context.** Rejected: the probe build showed the admission refusing next,
  and the envelope's constant would have journaled `paper` on a live workspace's streams.
- **Make the DEC-505 fallback take the run's connection too.** Not needed: it applies only to an
  unrecorded connection, for which the door chooses paper or refuses, and the fold runs before
  the door's connection is handed to the shell.

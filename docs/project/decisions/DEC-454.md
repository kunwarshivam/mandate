## Decision

1. E7-7 closes the integration defect between the runtime's legacy six-field
   `ModelOutputRecorded` writer and journal §9.1's already-accepted closed schema in the same
   consolidated pull request.
2. `mandate-runtime::ModelOutput` carries the typed facts needed to write and replay the closed
   payload. The runtime does not reconstruct an inline legacy `content` object.
3. The tracer's deterministic moving-average adapter supplies only facts already fixed by its
   validated mandate and DEC-157 item 4: the registered model content hash, `long` direction,
   conviction and confidence of one, expiry as the horizon, no thesis, no evidence, no
   invalidation, and no ignored reason.
4. The shell derives `artifact_refs` from digest references in a draft's payload and supplies the
   mandate version in `config_refs`. Missing referenced artifact bytes still fail journal
   verification; the shell does not exempt or invent them.

## Rationale

E7-9 already registered the binding schema, and E7-7 requires the runtime's real agent-stream
drafts to parse against it. Keeping the legacy writer would leave the accepted journal contract
unenforced at the integration boundary. Every value needed by this tracer already exists in the
validated mandate, injected clock, and deterministic signal mapping, so conformance needs no model
guess or safety relaxation.

## Alternatives considered

- Bypass the registered schema for the tracer: rejected because it weakens journal validation.
- Keep inline `content` alongside the closed fields: rejected because the schema is intentionally
  closed and replay must read the stored canonical shape.
- Defer the correction to another pull request: rejected under the founder's one-PR instruction
  because E7-7 cannot reach its accepted end-to-end path without it.

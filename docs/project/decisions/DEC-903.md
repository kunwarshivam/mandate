# DEC-903: The landing desktop's windows move as a Mac's do, the name is the product's own logo, and the signed-out pages' buttons are grey (amends DEC-467 item 9)

| | |
|---|---|
| **Status** | Accepted |
| **Date** | 2026-10-10 (UTC) |
| **Decided by** | The founder, who asked for window motion "like it actually happens on mac", for the ASCII art to give way to another retro style, and for the signed-out pages' buttons not to lead with yellow; the agent chose the details under DEC-79, since none touches money, legal text or a safety rule |
| **Story or claim** | Landing page (DEC-212, DEC-218, DEC-467); `web/design/plan.md` section E, "One era of type on the landing page" |

## Decision

1. **Windows move as a Mac's do** (`src/components/site/window-motion.ts`). A window opens by
   zooming out of whatever opened it: its desktop icon, a Start menu line, its taskbar button, a
   browser menu line or a button in the page; with nothing to zoom from (the owl's tour), out of
   its desktop icon. Minimize scales it down into its taskbar button, as the Dock's Scale effect
   does; the taskbar button brings it back the same way. Close shrinks it to 94% and fades it, as
   macOS closes a window. Maximize and restore morph the frame. Opening takes `--duration-window`
   (280ms, `--ease-out`), minimizing `--duration-window-exit` (220ms, `--ease-in-out`, since it
   travels), closing `--duration-dialog-exit` (150ms) and the frame `--duration-dialog` (240ms).
   Only transform and opacity animate; the window keeps its proportions as it zooms, so it is never
   stretched.
2. **It stays interruptible and quiet.** Every motion starts from where the window is on screen, so
   a click mid-flight turns it around: the taskbar button during a minimize brings the window back
   from where it got to. A window opened, closed or minimized from the keyboard (a click with no
   pointer behind it) changes at once, as `web/DESIGN.md` asks of keyboard actions. Under reduced
   motion a window fades in and out where it stands and maximizes at once. A browser without the
   Web Animations API changes state at once. The genie effect was left out: it needs a snapshot of
   the window warped on a canvas, which the content (forms, video, a live record) would not survive
   cleanly.
3. **The name is the product's own logo**, replacing the figlet ASCII of DEC-467 item 9: the brand
   owl beside the lowercase "owlhead" wordmark of DEC-203, in the logo's colour, as the app's header
   draws it (`OwlheadWordmark` and `BrandOwl` in `src/components/brand/`), 40px tall on a phone and
   48px from `sm`. It is aria-hidden behind the `sr-only` "Owlhead" `h1`. The founder chose it from
   nine directions (option H), over a dithered bitmap wordmark this decision first drew. VT323 stays
   the face of typed text (the address and the fields).
4. **The signed-out pages' buttons are grey.** The default button (`BUTTON` in
   `src/components/site/letter.ts`, and `LOGON_PRIMARY` on the sign-in pages) is the same bevelled
   grey as every other button, set apart by the extra ink ring a window's default button had. The
   sun highlight stays for the blinking "New" tag, a hovered or focused link and a selected desktop
   icon.

## Rationale

The windows appeared and vanished on a toggle, which read as a page swapping content rather than
a desktop. Zooming from the thing clicked shows where a window came from and where a minimized one
went, which is what the motion is for. The founder asked to move on from the ASCII art, and the
plan already preferred one era of type to block letters made of punctuation. Of the directions
shown (bitmap, outline, shadow, dot matrix, the owl as the O, the logo in pixels), the founder
picked the product's own lockup, so the landing page names Owlhead the way the app does. Yellow buttons made every page's main action the loudest colour on it; a Windows 98
default button was grey with a darker ring, which is quieter and truer to the period.

## Alternatives considered

- **The genie effect.** Rejected for item 2's reason.
- **Classic Mac zoom rectangles** (outlines stepping from the icon to the window). Truer to 1990s
  Macs but the window itself would still pop in; the founder asked for the motion of a Mac now.
- **A dithered bitmap wordmark**, drawn on the owls' pixel grid. Built first; the founder did not
  like it.
- **A Pixelify Sans wordmark, outlined or shadowed as System 7's Style menu did, or the owl as the
  O.** Shown; not chosen.
- **WordArt or chrome lettering.** Both lean on gradients, which `web/DESIGN.md` forbids.
- **Ink buttons.** A solid ink default button would be as loud as the yellow one in dark mode.

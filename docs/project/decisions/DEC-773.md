## Decision

1. **Interim:** every quoted model item of the causal trace (workspace API §4.8.1) is
   `platform_authored` until a decision says how the trace reads owner selection, as §4.8.1 says
   where the trace cannot tell.
2. **For the founder:** (a) should the output of an owner-selected signal model (mandate spec
   §6.4) read `owner_selected`, told from the event's `config_refs.mandate_version`, the confirmed
   mandate that names the model? (b) What does the label say? §6.4 writes "Output of software you
   selected"; the wording is compliance text ([compliance](../../product/08-compliance-and-regulatory.md)).

## Rationale

The conservative attribution: labelling the platform's ideas as owner-selected would understate
the platform's role.

## Alternatives considered

Reading `config_refs.mandate_version` now: it sets what an owner is told they chose, the founder's.

## Decision

1. **The exception.** #805 may exceed ES-13's 400-line split threshold (DEC-253 item 3), at about
   750 lines against `main`. All but about 60 of them are the pending tests in
   `crates/mandate-journal/tests/notices.rs` and decision text (DEC-720, which carries the schema
   closure, and this file). The rest is the stub `StreamType::Notice` variant, its three match arms,
   and the `BEHAVIOUR_ONLY_TESTS` rows. It covers #805 only; S2's implementation PR is held to
   ES-13 as usual.
2. **No split.** DEC-77 holds: the implementation PR changes the tests only by deleting their
   `#[ignore]` lines, and passes the mutation gate with 0 missed mutants.

## Rationale

The closure has to land whole. The four records' tables and twelve rules are one contract that the
dispatcher (E8-10) and the stream owners' alerts (E8-9) write against, and the review asked for
more of its cases, not fewer. Splitting it into two tests PRs would put half a closed schema on
`main` with nothing that pins the other half, and add a review cycle that catches nothing new.

## Alternatives considered

- **Two tests PRs**, one for the catalogue and stream type, one for the schemas and rules: rejected
  for the reason above.

| **Story or claim** | DEC-502; E7-19, E15-13; claim [#171](https://github.com/kunwarshivam/mandate/issues/171); [first paper trade brief](../tasks/first-paper-trade.md) |

## Decision

1. **Reading of DEC-475 item 1.** "A model gateway supplies a typed output carrying its registered
   model identity, version, content hash, instrument, observation time and expiry" names the
   supplier for models that are called through the gateway ([inference spec §1.1](../../specs/inference.md#11-in-scope)).
   A `quant.` model makes no model call and is outside the gateway
   ([inference spec §1.3](../../specs/inference.md#13-non-goals)). Its supplier is a **model host**:
   deterministic code that emits the same typed `mandate_runtime::ModelOutput`, which the
   production cycle verifies exactly as it would verify a gateway's (against the confirmed
   mandate's pin and the `model_registry` snapshot, [DEC-484](DEC-484.md) item 5). DEC-475's
   contract is the type and the checks on it, not the component that fills it. No model is called.
2. **Where the host lives.** A new crate, `mandate-modelhost`, layer 8, pure, safety-critical,
   beside `mandate-shell`. `xtask/layers.toml` lets a crate depend only on strictly lower layers, so
   neither crate can depend on the other: the shell cannot run a model, and the host cannot reach the
   builder's sizing, the gate, the journal, the executor or the connector. The host depends on
   `mandate-backtest` (the model's code), `mandate-runtime` (the output type), and lower-layer value
   crates. The paper adapter, a new layer-9 crate `mandate-paper`, composes the two: it hands the
   host typed inputs and hands the host's output to `ProductionCycle::run`. The layer and the two
   new crates are `xtask/layers.toml` and `CODEOWNERS` changes, which need the founder's review.
3. **The host evaluates only a pinned model.** It refuses unless three things agree: the confirmed
   mandate's pin (id, version, content hash, parameter keys), the one entry of the
   `model_registry` snapshot that matches it, and the content object the host itself computes for
   that id and version ([DEC-504](DEC-504.md)). It has no default parameter, no fallback model and
   no substitute. Every refusal is a missing output, which can only shrink a buy
   ([mandate spec §8.3](../../specs/mandate.md#83-order-builder-conviction_linear-dec-47-dec-60), MI-10).
4. **What carries over from the inference spec's invariants.** As host properties, each with a
   test: INF-1 (an id and version the host has no compiled content for is refused), INF-2 read as
   no substitution, INF-4 (every refusal yields no output), INF-5 (the output type carries no order
   field), INF-10's replay half (replay reads `ModelOutputRecorded` and never runs the host),
   INF-13 (exits, protective orders, kill switches and reconciliation never call the host), and
   INF-15 and INF-16 (the host writes nothing: no mandate, policy, registry or journal). INF-3,
   INF-6 to INF-9, INF-11, INF-12 and INF-14 govern calls, cost, prompts, caches, endpoints and
   provider keys, none of which a quant model has.
5. **Times.** `as_of` is the data cut-off of the inputs the host used, the end of the last
   complete bar, never the run clock ([mandate spec §8.2](../../specs/mandate.md#82-output)).
   `expires_at` is `as_of` plus the pinned `max_output_age_s`. A daily model's output is therefore
   fresh only for the age the owner pinned, counted from the close it read.
6. **Journaling.** The host is not a stream writer. The runtime appends the output as
   `ModelOutputRecorded` version 2, with `mandate_version` and `model_registry` in `config_refs`,
   before any decision (DEC-484). The record of the host's inputs is an `ObservationRecorded` the
   runtime appends before the output, its `data_ref` the closes stored as an artifact.
7. **The `ObservationRecorded` draft is corrected to the spec** (the coordinator's ruling on the
   brief's X-2, 2026-10-07, under DEC-176). The runtime's draft carries `source`, `instrument`,
   `at` and the data inline; journal spec §9.1 and the schema `mandate-journal` registers carry
   `source`, `instrument_id`, `as_of` and `data_ref`. The code moves to the spec and the registered
   schema, which adds no risk: today every such draft would be refused at append. That correction
   (the brief's slice R0) lands before the slice that journals the host's inputs (H3).
8. **Not on the first trade's path.** The model gateway (E15-6) and inference registry entries
   (E15-7) come with the LLM model, whose output enters the same production cycle API
   (DEC-502 item 2).

## Rationale

The founder chose to follow inference spec §1.3. DEC-475 item 1 was written before that choice
and names the gateway as the supplier; read literally it would need a gateway for a model that
calls nothing. The reading above keeps everything DEC-475 protects: the output is typed, pinned,
checked by the runtime against the confirmed mandate and the registry, and turned into an order
only by the builder, autonomy, gate and executor. Placing the host at the shell's layer makes
"no strategy inside the shell" a fact of the build rather than a rule a reviewer has to hold.

## Alternatives considered

- **The gateway hosts quant models too.** Rejected by the founder (DEC-502 item 2): a spec
  change and the gateway before the first trade, for a model that makes no call.
- **The strategy runs inside the shell.** Rejected: that is the E7-7 assembly DEC-475 item 6
  deletes; the shell would again select and run a model.
- **The host below the shell, called by it.** Rejected: the shell could then choose and run a
  model, which DEC-475 item 3 forbids. At the same layer it cannot.
- **A separate host process that hands its output over in a file.** Rejected: a file the cycle
  reads is a hand-fed output channel, which DEC-502 rejects.

## Decision

1. The executor's fee step owes an `AccountSnapshotRecorded` whose payload is every member
   journal spec v0.7 §9.2 closes: the eleven account members, `model_cash`, `cash_band`, and
   `cash_in_band` present as `null` (§4.2; rule 24 makes all three `null` together on a fee
   posting, which compares no cash), and the batch's `risk_clock` beside them. The vectors'
   `snapshot_fees` draft (`fixtures/refcases/journal.json`, `control_stream.drafts`) is the member
   list, as the reference validator checks it.
2. The writer lands as `reconcile::fee_step_snapshot_fields`, a stub answering
   `Unimplemented { story: "E7-10" }` until the implementation PR fills it and wires it into
   `fees` (DEC-77); `fees` keeps journaling today's reduced form until then, and
   `AccountSnapshotRecorded` stays unregistered (DEC-303).
3. The fee step's pause and alert never wait for the snapshot's own validation: a snapshot
   `append` refuses leaves the pause without a name to alert about, and the pause and the alert
   run all the same (`AGENTS.md` rules 3 and 13, DEC-261 item 7). The tail lands as
   `reconcile::fee_step_pause_and_alert`, stubbed the same way. Today `fees` journals the
   snapshot behind a `?`, which is the ordering the pending test holds against.
4. The pending tests of this PR pin the decision; the implementation PR deletes their
   `#[ignore]` lines and nothing else under `tests/`.

## Rationale

The fee step is the step that pauses every agent and alerts the owner (§11): a snapshot the
schema refuses must never hold that, or a refused writer would silence the one control a fee
difference has. Pinning the member set through the vectors keeps the writer and the reference
validator on one list.

## Alternatives considered

- Pin the reduced form and register the schema with a `null`-tolerant reader. Rejected: §9.1's
  absent-member rule is the spec's own words, and a schema that reads absence as `null` is a
  weaker schema, not a reader choice.
- Stub the whole `fees` step. Rejected: live tests drive it, so a stub there would break the
  crate's live suite, and DEC-77's stubs sit beside live behavior, never over it.

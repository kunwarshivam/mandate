## Decision

1. The runtime admits a `cli_confirm` step-up, and `mandate approvals approve` accepts a grant,
   for a live deployment only when all hold: the connection is Robinhood, the confirmed mandate
   is within DEC-529's limits (`max_order_usd` 100, the one instrument DEC-529 names), and the
   approver is the workspace owner.
2. Each admission and grant is journaled with the approver and the step-up kind before the
   order intent it releases.
3. Every other live deployment keeps refusing `cli_confirm`. This admission ends when E9-4's
   step-up authentication lands; a later decision then retires it.
4. Risk reduction is never gated by this (rule 13).

## Rationale

Without it no live opening can be approved before E9-4, which adds about a week. The scope
limits exposure to DEC-529's one small order.

- Wait for E9-4: no live order this week.

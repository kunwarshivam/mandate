|---|---|

## Decision

1. `IntentReceived` names its members as journal spec §9.1 closes them and the vectors' seq 2
   draft carries them: `intent_id`, `agent_id`, `instrument_id`, `side`, `type`, `tif`, `qty`,
   `limit_price`, `purpose` — never `agent`, `kind`, `instrument`, or `limit`. The writer lands
   as `intent::intent_received_fields`, a stub answering `Unimplemented { story: "E7-10" }`;
   `received` builds its pairs from it in the implementation PR. The protective prices stay
   beside this list, as `received` writes them today.
2. `OrderSubmitted` writes its optional members present as `null` when they are empty, never
   omitted (§4.2): `intent_id`, `limit_price`, `stop_price`, `order_class`, `take_profit`, and
   `stop` — the members `journal_rung` writes conditionally today, under the vectors' spelling
   `limit_price` where the vectors name the member. The writer lands as
   `intent::order_submitted_optional_fields`, stubbed the same way; `journal_rung` replaces its
   conditional members with it in the implementation PR.
3. The pending tests of this PR pin the decision; the implementation PR deletes their
   `#[ignore]` lines.

## Rationale

A draft that omits a schema-declared member is refused at that member, so an empty member must
read as `null`; and the executor's copies read the intent back by these names, so a rename the
vectors do not carry would strand the fold's own readers. The pins are read from the committed
fixture, so a vector change re-reads rather than passing silently.

## Alternatives considered

- Pin `OrderSubmitted`'s whole member set now. Rejected: the event's payload schema is not closed
  in §9.2, so the full set is not yet knowable; only the empty-members rule is owed here
  (DEC-174 item 5), and the shared members' renames ride with the implementation PR's own
  vector conformance.
- Write `null` for empty members on every account-stream event in this PR. Rejected: the same
  live-path reason as DEC-306's second alternative — DEC-77's stubs never change live behavior.

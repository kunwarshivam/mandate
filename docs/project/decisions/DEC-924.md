# DEC-924: The shell's unconditional live refusal is replaced by a gated admission

## Decision

1. `DeploymentRefusal::Live` in `mandate-shell`'s control is no longer unconditional. A live
   deployment is admitted only when all hold: the binary is built with `live`; the run passed
   `--confirm-live`; the live door's connection and unspent checks passed on the run's real
   records and held state (DEC-918, never the placeholder); and the MCP host is the pinned
   Robinhood host constant.
2. Any one missing still refuses `Live` before a credential is read.
3. The constant is Robinhood's published MCP host, set in one place behind `live`, and reviewed
   in the PR that sets it.

## Rationale

This is the last lock between the built live arm and a real order. Each condition is one the
founder controls or the door already verifies.

## Alternatives considered

- Keep the lock until the sim rehearsal passes: about one more day.

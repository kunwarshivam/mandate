## Context

DEC-2312 item 3 lets `ProtectionChanged` version 2 disclose a fractional position's unprotected
fraction on `unprotected_start` and `placed`. A position under one share built from several fills
places nothing, and its start is journaled at the first fill. If it fills 0.3 and then 0.1, the
start discloses 0.3. The position then ends at 0.4, and no record discloses that.

## Decision

1. **`unprotected_end` may carry the fraction too.** At version 2, rule 44 admits a non-null
   `unprotected_fraction` on `unprotected_start`, `placed`, and `unprotected_end`, strictly between
   0 and 1. On an end it is the fraction of a share the position holds when the interval ends,
   counting every fill the broker reported.
2. **The vectors pin it.** `protection_fraction` gains a valid draft with the fraction on an end.
   It also gains an invalid draft for each other action that discloses none, and a seeded
   validator mutant widening the actions by each of them, so no widening passes unseen.

## Consequences

- The executor writes the fraction on the `unprotected_end` that closes a fractional entry's
  interval, as well as on its start and its placement.
- Version 1 is unchanged. Nothing reads the fraction, so replay is unchanged.

## Alternatives considered

- **Disclose only on the start, and re-journal a start at each fill.** Rejected: a start opens an
  interval, and a second one would read as a new interval to the fold and the bound.
- **Leave the final size to the position records.** Rejected: §5.4 asks for the fraction to be
  disclosed, and the position record does not say what protection left uncovered.

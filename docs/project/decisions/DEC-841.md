# DEC-841: A re-placement with no asset class, or no profile, has no shape and is journaled and alerted

| | |

| **Decided by** | An agent (Claude Code, the builder of E7-23 B2a's implementation) |
| **Story or claim** | E7-23 B2a (claim #857); DEC-838 items 1 and 5; [first live trade brief](../tasks/first-live-trade.md) LT-2, LT-14 |

## Decision

1. **An instrument the instrument snapshot does not classify has no protective shape.**
   `protective_shape` reads the profile's row for the order's asset class and session (DEC-838
   item 4), so with no asset class there is no row to read. `re_place` routes it as DEC-838 item 1
   routes `None`: `unprotectable(...)` (an `expiry_unreplaceable` record and the
   `protection_expiring` alert) and an `unprotected_end` marked `uncovered`, whose interval stays
   open and bounded. Before B2a, such an instrument was read as "not crypto" and sent an OCO when
   a take-profit was recorded, or answered E7-4's stub without one.
2. **An executor whose transitional profile failed to build has no shape either.** The table is a
   constant and `CapabilityProfile::new` accepts it, so this is the defensive case; it takes the
   same path as item 1, never an error and never a silent skip.

## Rationale

Guessing the asset class to pick a row is the asset-class read of a broker rule that LT-2 removes.
A guessed equity OCO sent for an instrument that is not an equity would be refused by the broker,
which also leaves the shares uncovered, but without the shortfall named. The routed path names it
to the owner at once (`AGENTS.md` rules 3 and 13).

## Alternatives considered

- **Read an unclassified instrument as a US equity**, as `session.rs` reads its sessions (#400
  round 1, minor 3): failing closed there holds an order; here it would send one the profile was
  never asked about.
- **Return an error:** DEC-838 item 1 rules out an error for a missing shape.

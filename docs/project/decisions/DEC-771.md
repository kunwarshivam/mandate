## Decision

1. **The exception.** [#797](https://github.com/kunwarshivam/mandate/pull/797) may exceed ES-13's
   400-line split threshold for safety-critical crates (DEC-253 item 3): about 555 lines in
   `crates/mandate-audit/`, about 155 over, of which about 45 came from taking a
   `mandate_identity::Tenant` in place of a bare workspace id (identity spec ID-8; DEC-770 item 4):
   the helper that builds a real `TenantContext` and the ULID workspace fixtures. The overage is
   tests and fixture (`tests/common/mod.rs`, `tests/pages.rs`); `src` is types and `Unimplemented` stubs only, the
   public types workspace API §4.8.1 names; no logic is over the limit.
2. **Scope.** The exception covers #797 only. #798 and #799, and every later `mandate-audit` slice,
   are held to ES-13 as usual. DEC-77 holds: #799 changes the tests only by deleting `#[ignore]`
   lines, and each PR passes the mutation gate with 0 missed mutants.

## Rationale

- Aligning #797 with workspace API §4.8.1 (#767) added the spec's page, head and stream-list types
  to the stub; splitting the types from the first tests that exercise them would leave a PR of
  declarations no test reaches.
- The independent review passed #797 and counted the overage as above.

## Alternatives considered

- **A further split.** It would add a review cycle and catch nothing new, since the excess holds no
  logic.

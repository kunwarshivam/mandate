## Decision

1. **The exception.** #837 may exceed ES-13's 400-line split threshold (DEC-253 item 3), up to
   about 840 changed lines against `main`, counted over its non-generated files (`src/` of
   `mandate-journal` and this file), as DEC-651 allowed for E9-1.
2. **Conditions.** All of them hold on one head SHA before it merges:
   - two independent review passes by Sonnet on that head, both PASS on the exact SHA: pass 1
     reads `agent.rs` and the hold (DEC-673's anchored `held_mismatch`); pass 2 reads
     `workspace.rs`'s records, the schema tables, and `check_batch`;
   - zero missed mutants in CI's mutant shards on that head;
   - no further growth: a later round that needs more lines splits the work instead.

## Rationale

- **No split below about 650 lines is possible without changing #829.** #829's
  `every_e10_15_draft_parses_or_is_refused_as_its_case_says` is one table-driven test over all
  three sections (§9.9, §3 with §9.10, §9.11), so no partial implementation can delete its
  `#[ignore]` line, and DEC-77 lets the implementation change the tests only by those deletions.
- **About 200 of the lines are static schema tables**, which read as data, not logic.

## Alternatives considered

- **Split #829's test per section and implement each in its own PR.** Rejected: it reopens a
  reviewed tests PR and adds review cycles over the same tables.

# DEC-460: Close the tracer's remaining emitted journal schemas

| | |
|---|---|
| **Status** | Accepted |
| **Date** | 2026-10-05 (UTC) |
| **Decided by** | The implementing agent under DEC-79 and DEC-176 |
| **Story or claim** | E7-7; claim [#171](https://github.com/kunwarshivam/mandate/issues/171); [PR #598](https://github.com/kunwarshivam/mandate/pull/598) |

## Decision

1. `ApprovalRequested` schema version 1 is a closed agent-stream record. Its top-level members are
   required `instrument`, `asset_class` (`us_equity` or `crypto`), `side` (`buy`), canonical
   decimal `qty` and `limit`, `purpose` (`open` or `increase`), digest-ref `mandate_version`,
   non-empty `decided_by`, canonical decimal `combined_score`, nullable `reference_mark`
   (`{price: decimal, seq: integer}`), integer `approvers_required`, boolean
   `independent_required`, integer risk-clock seconds `deadline`, integer `timeout_s`,
   `on_timeout: skip`,
   `content`, and digest-ref `content_hash`.
2. `ApprovalRequested.content` is closed recursively, never an open object. It has:
   - `action`: `instrument`, `asset_class`, `side`, `qty`, `limit`, decimal `order_usd`, and
     `purpose`, with the vocabularies in item 1;
   - `trigger`: digest-ref `mandate_version` and non-empty `decided_by`;
   - `evidence`: `combined_score` with the fixed label
     `combined model score, not a probability of profit` and decimal `value`, plus `outputs`, each
     with ULID `event_id`, nullable digest-ref `artifact`, and label
     `Output of software you selected` or `platform-authored`;
   - `risk_impact`, each with `field` (`order_usd`, `position_usd_after`, `gross_usd_after`,
     `bought_today_usd`, `drawdown`, or `daily_pnl_fraction`), decimal `value`, and nullable
     decimal `cap`;
   - nullable `reference_mark`, whole-second timestamp `deadline`, the fixed default
     `If you do nothing, this action is skipped`, choices exactly `["approve", "skip"]`, and
     `approvers` with integer `required` and boolean `independent`.
3. Every duplicated top-level approval member equals its nested content member; the top-level
   integer deadline and nested timestamp name the same whole second. `content_hash` equals the
   SHA-256 digest reference of the canonical `content` object. This keeps what replay binds
   identical to what the owner reads and confirms.
4. `ApprovalDelivered` schema version 1 is a closed agent-stream record with ULID `approval`,
   `channel: cli_inbox`, `status` (`delivered`, `suppressed_quiet_hours`, or `failed`), and
   nullable non-empty `message_id`.
5. `BrokerPositionObserved` schema version 1 is a closed account-stream record with non-empty
   `instrument`, decimal `broker_qty` and `model_qty`, boolean `mismatch`, and whole-second
   `risk_clock`.
6. `AgentModeApplied` schema version 1 is a closed account-stream record with non-empty `agent`
   (including the executor's `*` all-agent sentinel), `to` (`normal`, `exits_only`, `paused`, or
   `stopped`), non-empty `restriction`, boolean `originated`, and whole-second `risk_clock`.
7. `CompensatingEvent` schema version 1 is a closed account-stream record with non-empty `subject`,
   `difference: order_state`, `from` and `to` from the complete executor order-state vocabulary,
   `corrected_event_ids` as ULIDs, and whole-second `risk_clock`.
8. New appends require every listed member and refuse extras. Existing replay folds remain
   tolerant of historical sparse rows; no writer lifecycle or append outcome changes.

## Rationale

These are the exact existing runtime, approval-content, executor reconciliation, and batch-stamped
writer forms. Their missing registrations made valid ASK and reconciliation batches fail closed as
`unknown_schema`. Closing the complete writer/fold union restores those governed paths while
preventing unregistered members, content drift, or a different approval object from entering the
journal.

## Alternatives considered

- Use `OpenObject` for approval content: rejected because a future ungoverned member could change
  what the owner sees or what replay binds.
- Register only the tracer's happy-path values: rejected because delivery status, asset class,
  purpose, evidence authorship, risk-impact fields, modes, and order states are governed
  vocabularies already emitted or folded.
- Relax unknown-schema validation: rejected because journal validation must fail closed.

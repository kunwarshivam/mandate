## Context

DEC-787 item 5 covers a cold store that cannot be read, not one whose manifest disagrees with the
hot `SegmentExported`; item 3 refuses a failing start record without telling anyone; and §11 never
says whether the hot rows a run walks are the rows the segment file holds.

## Decision

1. **A cold manifest that disagrees with the hot record refuses the start** (Q1). When the cold
   store returns the start segment's manifest and its digest is not the record's `manifest_hash`,
   the start is 422 `trusted_start` and nothing is recorded: no `VerificationRun`, and no
   `segment_manifest_mismatch`, since no range was entered. It is `TrustedStartError::Refused`, not
   `ColdUnreadable`: the store answered.
2. **A start record that fails its own checks is refused** (Q2), as DEC-787 item 3 says, with
   nothing recorded. An operator alert for it, carrying only opaque IDs and generic text, is a
   separate story, E12-7 in the backlog; until it lands the refusal is the only signal.
3. **The run compares each segment's hot rows with its cold file** (Q3). For the trusted-start
   segment and every segment in the range, the run exports the hot rows it read for that segment's
   `first_seq` to `last_seq` in §6.2's format (`export_segment(rows)`), and that file's SHA-256
   must equal the manifest's `file_sha256`. A difference fails a new §11 per-range check,
   `segment_rows_mismatch`, reported for the range (`seq` null). Lane L2 writes the check's text in
   journal spec v0.38 (pending); until then this item records the decision, and the run's
   implementation waits for that version.

## Rationale

The cold store is what an attacker with the hot store cannot rewrite (object lock, §6.2), so a
disagreement is DEC-115 item 5's refused case; refusing records nothing and adds no risk. An alert
is a new surface (`AGENTS.md` rule 6), so it gets its own story. Without item 3 a run could pass hot
rows rewritten and re-chained after export while the cold manifests stayed right.

## Alternatives considered

- **Record `segment_manifest_mismatch` for a disagreeing cold manifest.** Rejected: no range was
  entered, and a start that cannot be trusted is a refusal, as DEC-787 item 5's outage is.
- **Fall back to the hot record when the cold manifest disagrees.** Rejected: it is the start
  DEC-787 item 5 refuses.

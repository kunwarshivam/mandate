## Decision

Reserved. The coordinator ruled on #895's open question that `run_observed` refuses an output whose
`as_of` window or instrument does not match the observation it answers, on the `run_observed` path
only, which reaches only openings; exits stay outside it (`AGENTS.md` rule 13).

The H3 implementation PR does **not** implement the refusal. #895 pins no test for it, and any
implementation leaves a mutant the existing tests cannot kill: the host's observation and output
always agree in those tests, so swapping `||` for `&&` between the two comparisons, or replacing
the comparison with "never mismatched", passes them all. Under DEC-137 and the dispatch, the rule
stays out until a tests correction pins it; that PR fills in this decision and sets it Accepted
under DEC-176 (it only tightens the opening path and adds no risk).

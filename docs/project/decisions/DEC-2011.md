## Decision

The founder's words, as relayed by the coordinator:

1. Hosted infrastructure is OpenTofu + DigitalOcean managed Kubernetes (DOKS) + GitOps, with a
   staging and a production environment. Cloud tokens live in GitHub environments behind the
   founder's approval, so agents never see them. This replaces deploy/hosted/cell1.py's droplet
   bring-up (DEC-2001's droplets; amend DEC-2001 and DEC-2005/2006 where they conflict).
2. The monthly cloud budget cap is $150 for staging plus a small production, with alerts at 80%.
3. The target is staging up by the demo on 2026-10-26.
4. Separately, DEC-2103 item 7, passkey-only sign-in in v1, is accepted. Lane L1 records that one,
   not lane IAC.

## What it amends

- **[DEC-995](DEC-995.md) item 5, "no DigitalOcean managed database, managed Kubernetes or load
  balancer":** managed Kubernetes is now the platform. A managed database and a load balancer stay
  out: the journal's Postgres is still CloudNativePG in the cell (DEC-967 item 8), and the only
  ingress is still the Cloudflare Tunnel. DEC-995's other items stand where item 1 above does not
  replace them: New York (`nyc3`), no public port, Cloudflare Tunnel and Access.
- **DEC-995 item 3's price** is replaced by item 2's cap for both environments together.
- **DEC-2001 (open in #1539):** its droplets, cloud-init, k3s units and `cell1.py`'s `droplets`
  and `nodes` steps are replaced by OpenTofu under `deploy/tofu/` (E21-56). Its rules that do not
  depend on droplets carry over: no inbound port from the internet, ingress only through a
  Cloudflare Tunnel, Access in front of the API's hostname, and secrets never in a committed file
  or on a command line. Its items 6 (the `dev` tier) and 7 (`doctl`) stay the founder's questions
  as written; item 7 is moot for infrastructure, which no longer calls `doctl`.
- **DEC-2005 and DEC-2006 (open in #1539):** their chart rules (one `deploymentTier`; a
  synchronous standby and a WAL archive) stand. Where DEC-2006 item 3 leaves the archive's bucket
  to the founder, item 1 above places it in DigitalOcean Spaces, made by OpenTofu (E21-56).
- Those three files are not on `main` yet, so this PR cannot edit their status lines. Lane H edits
  them to name this decision when #1539 next merges `main`, or lane IAC does once they land.

## Rationale

The founder chose it. Managed Kubernetes removes the node bring-up DEC-2001 had to script by
hand (cloud-init, k3s, the join token, an ops tunnel whose token sat in user data), and an
environment per directory with its tokens behind a GitHub environment keeps every credential out
of agents' reach, as DEC-1005 already does for `web/`.

## Alternatives considered

The founder decided between the coordinator's options; lane IAC records the decision and does not
re-open it. [ADR-0006](../../adr/0006-hosted-infrastructure-as-code.md) lists the engineering
alternatives lane IAC weighed inside it.

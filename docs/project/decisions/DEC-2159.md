## Context

DEC-2151 item 2 sent an owner's request (`requested_by` `owner`) through the mandate's autonomy
rules like any proposal, so under the demo mandate, whose rule for `open` is `ask`, the owner's own
"Ask agent to buy" stopped in `/approvals` and waited for the same owner to approve it a second
time. The founder ruled against that, in his words: "why isnt this as simple as message", and on
#2968: "My own requests to my agent ("buy 10 AAPL") execute directly with no approval step.
Limits still apply."

## Decision

1. **An owner's own request is `auto`** (the founder). A request the owner submits through
   `POST /agents/{id}/requests` (`requested_by` `owner`) is not routed to `/approvals` by the
   mandate's autonomy rules: submitting it is the owner's approval. This supersedes DEC-2151
   item 2.
2. **Everything else still applies.** The order builder sizes nothing new and only clips the
   requested size to the mandate's caps (DEC-2151 item 3); every risk gate check applies, US
   account rules, eligibility, conduct controls, limits and the drawdown ladder among them; a gate
   `deny` is still a denial, and the agent's mode holds or refuses it as it does any opening. The
   envelope never changes (`AGENTS.md` rules 1, 11).
3. **Owner only.** It covers `requested_by` `owner`, the owner's own session. A request from a
   client or an owner-connected agent (DEC-141, `requested_by` `client`) keeps the mandate's
   autonomy rules, and no API route serves a client request yet (DEC-2151 item 4).
4. **The runtime half is lane X's.** How the runtime records an owner request's autonomy outcome
   is lane X's, in DEC-2858. The API's checks (§3.11 item 13) do not change.

## Rationale

The autonomy rule `ask` exists so that an action the platform originates waits for the owner. A
request the owner typed is already the owner's decision, so asking again adds a step and no
safety: the risk gate, which binds the mandate's limits independent of who asked (`AGENTS.md`
rule 1), still judges every order.

## Alternatives considered

- **Keep item 2 and let the demo mandate say `auto` for `open`.** Refused by the ruling: it would
  make every platform-originated opening `auto` too, which widens far more than the owner's own
  request.
- **Skip the gate for an owner request as well.** Not done: the ruling removes only the second
  approval, and no owner input may take an agent outside its mandate (`AGENTS.md` rule 1).

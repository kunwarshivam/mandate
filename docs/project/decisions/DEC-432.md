## Decision

The [inference spec](../../specs/inference.md) v0.1 is the draft contract for every model call and
the model gateway. It restates DEC-67 (no substitution), DEC-04 (opinions only), DEC-120 (the
research cost cap), and HLD §9 and §10, and adds these readings.

**Accepted (agent):**

1. **The call deadline is pinned with the model.** `deadline_ms` is in the registry entry and inside
   the content hash the mandate pins, so it changes only with a new model version the owner
   confirms (rule 11). Policy may set a platform maximum (spec §3.4).
2. **A late response is discarded.** A response completed after its deadline never becomes an
   output, in that evaluation or any later one (INF-3).
3. **No retry on content failures.** Only transport failures retry, only to endpoints serving the
   identical pin, and only within the deadline. A schema failure, identity mismatch, or provider
   refusal ends the call (spec §3.4).
4. **Cost is reserved before the call.** The gateway reserves the call's maximum cost against every
   cap before the first attempt and refuses a call that could take spend above a cap. A reservation
   left by a crash counts as spent for that risk day, and spend never decreases within a risk day.
   Mandate spec §8.5 check 7 is unchanged (spec §7.3).
5. **Prompts hold only the model contract's inputs.** No credential, account identifier, personal
   data, or other workspace's data; a deterministic guard checks before sending. The research
   agent's own memory stays allowed, as mandate spec §8.4 says (INF-8, spec §8.3).
6. **The cache is exact and per workspace.** Same workspace, same identity, same canonical request
   digest; no similarity cache; errors never cached (spec §3.5).
7. **The gateway gives models no tools,** no function calls, and no browsing (INF-5).
8. **Hybrid and on-prem deployments are local-only by default.** A customer may allow hosted
   endpoints in policy (spec §6). This only restricts.
9. **Quantization is part of an open-weight model's identity.** An endpoint serving another
   quantization is a different model under DEC-67, so an aggregator must lock routing to endpoints
   serving the identical weights (spec §4.1, §6).
10. **The reported identity must equal the pin.** A response whose provider-reported model differs
    fails as `identity_mismatch`, and its output counts as missing (INF-2).
11. **`ModelInvocationRecorded` needs these members when it closes:** call id, purpose, identity and
    endpoint, request digest, sampling parameters and seed, prompt and response artifacts,
    reported identity, provider request ID, outcome, attempts, token counts, cost, price table
    reference, cache hit, deadline, and completion time. The caller appends it, as the single writer
    of its stream, and reservations go to a new gateway-owned meter stream. Both are journal spec
    changes for E15-8, spec first; this item does not change the journal spec.
12. **RAID R-07's mitigation means a new mandate version, never a runtime fallback.** "Laya
    self-hosted as fallback; LLM wrapper fallback" is read under DEC-67: if Jev is lost, an owner may
    confirm a new version that pins another model; the gateway never routes to it. R-07's wording is
    updated to say so.

**Proposed (founder):**

13. **The fast tier (Laya, Jev; OD-02).** Neither model is defined or built. Options: build an
    open-weight fast model, use a hosted one, or drop the tier for v1. **Recommendation: drop it for
    v1,** keeping the `fast.` prefix and the call contract, and revisit OD-02 at Phase 3 with its
    bake-off. The retail profile already excludes `fast` until counsel answers question 33.
    Meanwhile: no fast-model code, vendor, or spend.
14. **Providers and hosting.** **Recommendation:** direct provider APIs pinned to dated snapshots
    for the research agent and the compiler on managed; an aggregator only for internal evaluation
    and the spike, with routing locked; self-hosted open weights as the local path after v1.
    Meanwhile: no new paid service; live calls only in the team's internal paper workspaces with the
    key already provided for the spike.
15. **Provider data terms.** **Recommendation:** offer only endpoints whose terms exclude training on
    API data, with the shortest retention available, kept on file per endpoint as part of the
    evaluation gate. Counsel confirms the wording.
16. **Bring-your-own provider keys for hybrid.** **Recommendation:** allow it for hybrid and on-prem,
    so the customer pays the provider directly and token billing at cost plus margin applies only
    to our keys; the meter still counts usage for quotas. Meanwhile: platform keys only, in internal
    workspaces.

## Rationale

The HLD names the model gateway and its duties in one paragraph, and the only model code is a spike.
The gateway sits between untrusted text and the order builder, and it spends money on every call.
Each reading picks the option that adds no risk: an output that might be from another model, late,
resampled, or built from another tenant's data is treated as missing, and missing outputs already
cannot enlarge a buy (MI-10). Items 13 to 16 involve vendors, spending, or legal terms, which DEC-79
reserves.

## Alternatives considered

- **Retry schema failures once.** Rejected: resampling until an output parses selects outputs, and
  the cost is the user's.
- **Let a late response serve the next evaluation.** Rejected: it would be an output computed for
  other inputs, under a deadline it missed.
- **Count spend only on completion.** Rejected: a crash between the provider's bill and the journal
  would undercount and let spend pass the cap.
- **A deadline set in policy rather than pinned.** Kept only as a maximum: the deadline changes which
  outputs arrive, so it is part of the model's behavior the owner pins.
- **A shared cross-workspace response cache.** Rejected: a tenant-isolation risk for a small saving.

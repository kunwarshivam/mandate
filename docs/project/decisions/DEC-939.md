## Decision

1. The judge's rule that a quote or asset record stamped after the run's clock is refused
   (`AheadOfClock`) stays exact. No clock tolerance is added.
2. `mandate-paper` is run only on a host whose clock is disciplined by NTP: `chronyc tracking`
   reports `Leap status : Normal` with `System time` under 5 ms (or `timedatectl show -p
   NTPSynchronized` is `yes` under systemd-timesyncd). The operator records that output in the
   evidence before the dry run. A host that cannot reach an NTP server does not run E2.
3. The cloud agent sessions used on 2026-10-16 do not qualify: their egress refuses UDP 123 and
   external DNS, and their clock trailed SPY's IEX quote stamps by up to 24 ms (#1355).

## Rationale

The second E2 refusal was correct: the host clock trailed the exchange, so fresh quotes looked
future-dated. Fixing the clock keeps the check exact. A tolerance would loosen a safety check.

## Alternatives considered

- A fixed tolerance for quotes stamped slightly ahead of the clock: rejected by the founder in
  favour of this option. It would also need a DEC-79 founder decision to loosen the check.
- Setting the host clock from Alpaca's own quote stamps: not a time source; it would only tune the
  host until the check passes.

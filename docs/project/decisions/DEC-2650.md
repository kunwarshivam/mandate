# DEC-2650: the decision files fold into one file per category, with stable anchors

| | |
|---|---|
| **Status** | Accepted |
| **Date** | 2026-10-29 (UTC) |
| **Decided by** | an agent, on the founder's instruction of 2026-10-29 ("trim decision bloat") |
| **Story or claim** | no story; the decisions directory. Amends [DEC-344](earlier-303-599.md#dec-344) |

1. The decisions directory folds into one file per category, by DEC-344's own number ranges:
   `infrastructure.md` (2000s), `workspace.md` (2100s), `intelligence.md` (2200s),
   `trading-core.md` (2300s and 2800s), `web.md` (2400s), `notifications.md` (2500s),
   `process.md` (2600s), `control-plane.md` (2700s, when it stops being empty), and
   `earlier-303-599.md`, `earlier-600-899.md`, `earlier-900-1999.md` for the decisions before
   DEC-2000. `04-decision-log.md` keeps DEC-01 to DEC-302, which were never files.
2. Each category file opens with a one-page summary of the rules still in force, then holds the
   decisions verbatim, demoted one heading level, each section opened by a stable
   `<a id="dec-<n>">` anchor above its heading. Links to a folded decision read
   `<category>.md#dec-<n>`; a bare `DEC-<n>` mention in prose stays as it is.
3. A per-decision file is kept when a forbidden path still cites it (`crates/`, `web/`,
   `docs/specs/`, `deploy/cell/charts/`, `deploy/cell/model-gateway/`, `schemas/`, `fixtures/`),
   when its status is not yet settled (the file is the reservation, per the README), or when it
   is Released. Everything else folds.
4. A new decision still starts as its own file under `docs/project/decisions/DEC-<n>.md`, the
   file reserving its number (DEC-344 unchanged); folding into the category file happens when the
   decision settles and no forbidden path cites it. The guard
   (`.github/scripts/decision-numbers.sh`) checks a number is taken once, by a file or by a
   category section, and that a section carries its matching anchor.

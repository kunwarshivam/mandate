# DEC-917: The ES-22 split guard does not count a crate's tests-directory files as code

| | |
|---|---|
| **Status** | Reserved |
| **Date** | 2026-10-11 (UTC) |
| **Decided by** | Held by the spec-guard carve-out lane, for the founder under DEC-79 |
| **Story or claim** | ES-22 (ADR-0001); the spec guard's refusal of PR [#1320](https://github.com/kunwarshivam/mandate/pull/1320) |

## Decision

Reserved. The spec guard classifies every `crates/` path as code, so it refuses PR #1320 — a spec
change whose only Rust change is `crates/mandate-journal/tests/connection_fold.rs`, a tests file —
with "specs, schemas, or reference cases changed together with code (1 code files); split the
change", although every possible split of that PR is mutually red. This reservation is for the
carve-out PR that reads `crates/<crate>/tests/**` as tests, not code, and proposes the decision to
the founder.

# DEC-2652: The runner's macOS job runs on macOS 15

| | |
|---|---|
| **Status** | Accepted (agent: a reversible engineering decision under DEC-79 that moves one job to a supported runner image and removes no check) |
| **Date** | 2026-10-30 (UTC) |
| **Decided by** | An agent (Claude Code), on the founder's instruction to fix CI, under DEC-79 |
| **Story or claim** | #3024's and #3025's `fast-portable` on 2026-10-30; supersedes [DEC-954](DEC-954.md) item 5's runner label only |

## Decision

1. `fast-portable` runs on `macos-15` in place of `macos-14`. Everything else in DEC-954 item 5
   stands: the job runs `cargo xtask ci portable`, the default build only, and the required `fast`
   verdict needs it.
2. The xtask test that lists the allowed `runs-on` labels allows `macos-15` in place of
   `macos-14`.

## Rationale

GitHub retires the macOS 14 runner image on 2026-11-02 and is running scheduled brownouts before
then ([actions/runner-images#13518](https://github.com/actions/runner-images/issues/13518)). On
2026-10-30 a brownout cancelled `fast-portable` on #3024 and #3025 after 23 seconds, before any
step ran, so the required `fast` check failed on two pull requests whose other jobs all passed.
After 2026-11-02 the job could not run at all.

## Alternatives considered

- **`macos-latest`.** Rejected: a floating label moves the image under the job without a change
  to review, and the guard's allowed labels are exact.
- **Dropping the job.** Rejected: DEC-954 keeps the runner building where the founder runs it.

## Decision

1. #825, the E7-12 tests PR for the permission checks, may exceed ES-13's limit of 400
   non-generated lines for a change to a safety-critical crate
   ([ADR-0001](../../adr/0001-engineering-setup.md) ES-13). It has about 1,000 hand-written
   lines:
   - `crates/mandate-connections/src/tests/checks.rs`, about 790;
   - `crates/mandate-connections/src/checks.rs`, its stubs and report methods, about 220;
   - [DEC-674](DEC-674.md) and [DEC-676](DEC-676.md), about 145.
2. The waiver covers #825 as it stands. It grows no further: any further change to it is split
   into a PR of its own.

## Rationale

- **The PR is mostly tests.** About four-fifths of its lines are the pending tests and their
  tables.
- **It has already been reviewed.** Several review rounds have read it, each against planted bugs.
- **Splitting cannot reach 400.** The test file alone is near 800 lines, because each check's
  cases share one set of fixtures and one report helper. Cutting it up would leave pieces that
  cannot be reviewed alone, and would cost the reviews already done.

## Alternatives considered

- **Split #825 into stacked PRs.** Rejected for the reasons above. Each piece would still exceed
  400 lines or depend on the others' fixtures.

## Decision

1. **The exception.** Three PRs of the `mandate-rh-sim` stack may exceed ES-13's 400-line split
   threshold (DEC-253 item 3). Each is counted over its own diff against the PR below it. The
   first figure counts `crates/mandate-rh-sim/` alone; the second, from the coordinator's
   re-review, also counts the wiring outside the crate.
   - **#712:** the crate skeleton, its API and the account tests. 435 lines in the crate, about
     472 in all.
   - **#714:** the order-rule and lifecycle tests. 465 lines in the crate, about 469 in all.
   - **#718:** the implementation. 470 lines in the crate, about 472 in all.

   #716 (299 lines) is within the limit and needs no exception. The exception covers these three
   PRs only. Later `mandate-rh-sim` slices (S2 onward) are held to ES-13 as usual.
2. **No split.** The three PRs land as they are, in stack order: #712, #714, #716, #718. Each is
   brought onto `main` after the one before it merges. DEC-77 holds:
   - #718 changes the tests only by deleting ignore lines;
   - each PR passes the mutation gate with 0 missed mutants.

## Rationale

- **A test double.** `mandate-rh-sim` is the simulated Robinhood broker (DEC-124, DEC-441
  items 11 and 16). It never runs in a trading path and has no live feature. At layer 10 it sits
  above every product crate, so no crate can take it as a normal dependency, and it stays out of
  every production dependency graph.
- **What the overage is.** It is mostly tests (the order-rule table, the lifecycle examples) and
  the crate doc's declared readings, which the review asked for. It is not added logic.
- **Already reviewed.** The independent review passed the full content of every PR, with every
  functional finding fixed and 0 missed mutants. Splitting now would add review cycles and catch
  nothing new.

## Alternatives considered

- **Split each PR to 400 lines.** Rejected. The content is already reviewed, so a split adds three
  more review cycles. It would also cut the order-rule table and the implementation through the
  middle, away from the tests that cover them.
- **Leave the overage unrecorded.** Rejected. ES-13 holds by review, and an exception the review
  grants is written down so that it cannot spread unrecorded.

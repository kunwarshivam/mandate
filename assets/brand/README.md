# Mandate brand assets

## Primary logo
- `mandate-lockup.svg` — primary horizontal logo, symbol + wordmark
- `mandate-lockup-reversed.svg` — reversed logo for dark backgrounds
- `mandate-lockup-480.png`, `mandate-lockup-960.png`, `mandate-lockup-1840.png` — raster exports

## Symbol
- `mandate-mark.svg` — standalone mark
- `mandate-mark-reversed.svg` — reversed standalone mark
- `mandate-mark-{32,64,128,256,512}.png` — raster mark exports

## App icon
- `mandate-app-icon.svg`
- `mandate-app-icon-{64,128,256,512}.png`

The SVG wordmark is converted to vector paths, so it has no runtime font dependency.
